# Actovia

An AI assistant that runs on your own machine — chat, deep research, a knowledge base, multi-agent groups, coding-agent employees and computer use — with an iPhone companion.

<img src="https://raw.githubusercontent.com/actovia-ai/actovia/master/build/icon.png" width="96" alt="Actovia's mascot, Ody">

Actovia is a cross-platform desktop app that runs a full local backend on your computer. It talks to OpenAI, Azure, Anthropic, Google, xAI and Ollama, and adds tools, Deep Research, an optional self-hosted knowledge base (LightRAG), Philharmonic groups of agents (whose employees can be your own Claude Code or Codex), MCP, memory, Computer Use on macOS and an app lock.
